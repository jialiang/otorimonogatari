# otorimonogatari

I downloaded this video back in 2018 and recently noticed that the original YouTube channel that uploaded it has since been deleted by the owner.
So I'm re-uploading it to restore it to the Internet. The video in this repo is a exact copy of what yt-dlp downloaded back then and represents the highest quality stream it could fetch at the time.

From what I could see, it was created and uploaded to the YouTube channel yunoha.A (@yunoha.a2589, channel ID UCofHRQGWKwPh03rQycPus5Q) on 2016-01-07 and existed under the URL https://www.youtube.com/watch?v=51MPyHWirrQ.
